## DOI (recommended)

Create a DOI for the GitHub release via Zenodo:

1) Log in to Zenodo and connect your GitHub account.
2) Enable the ASCEND repository in Zenodo.
3) Create a GitHub Release.
4) Zenodo will archive the release and generate a DOI.
